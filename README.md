# My Portfolio

მარტივი პირადი პორტფოლიო ვებსაიტი, რომელიც შექმნილია HTML და CSS-ით.

## სტრუქტურა

- `index.html` - მთავარი გვერდი პორტფოლიოსთვის
- `contact.html` - კონტაქტის გვერდი კონტაქტური ფორმით
- `style.css` - სტილების ფაილი

## ფუნქციონალურობა

- მთავარი გვერდი "About Me" სექციით
- კონტაქტის ფორმა მომხმარებლის შეტყობინებებისთვის
- რესპონსიული დიზაინი
